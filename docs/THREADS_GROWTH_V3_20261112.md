# 지원금픽 Threads 성장 개선 v3 — 실행기 연동 명세

대상: @hid_1004 / kllollain-max/supportpick
상태: **운영 정책 명세. 실제 게시기 연동 및 정규 게시 검증 전에는 적용 완료로 표시하지 않는다.**
적용 범위: 실제 실행기에 반영된 뒤 시작하는 신규 미착수 회차만.

## 불변 조건
- KST 08:00 / 12:00 / 16:00 / 20:00, 하루 최대 신규 본문 4건. 신규 예약 생성 금지.
- 기존 이미지/텍스트 교대 상태를 게시 성공 원장에서 복원. 실패/날짜 변경으로 순서 초기화 금지.
- 본문 1개 완결, 자동 답글 기본 0개, 해시태그 금지.
- 본문/답글에 URL, 도메인, 단축/우회 주소 금지.
- 마지막 줄은 정확히 `자세한 사항은 프로필링크 확인` 한 번만.
- 기존 게시기, 원장, 작업 잠금, 재시도, 보고 대화, 이미 완료된 원고와 게시물 보존.

## 생성 파이프라인
1. 공식 출처에서 제도 유효성·대상·금액·신청 기간·방법 확인. 미확인 내용은 단정 금지.
2. 마감 임박(확인된 경우), 생활밀착형, 청년/취업/육아/주거/의료/에너지, 조건 오해 해소 순으로 독자 효용을 평가. 지역 한정이면 첫 문장에 지역명 명시.
3. A 혜택 발견 / B 조건 / C 마감(확정 시) / D 오해 해결 / E 저장·공유 중 직전과 다른 유형 선택.
4. 첫 문장: 대상 + 검증된 혜택 + 확인 이유. 허위 긴급성 금지.
5. 본문 기본 250~450자, 1~3문장 단락, 모바일 우선, 참여 유도 최대 한 문장.
6. 이미지 회차: 1:1, 핵심 문구 1개 + 보조 문구 1개, 작은 브랜드 표시, 매회 다른 구성. OCR/시각 검수로 금액·오탈자·잘림 검사. 이미지 실패를 성공으로 기록 금지.
7. 게시 전 검사: 공식 출처 증거, URL/도메인/해시태그 금지, 마지막 CTA 정확히 1회, 기존 원장 중복 키 검사.
8. 게시 결과의 실제 ID를 확보한 경우만 성공 처리. 재시도 전 동일 키/게시 ID 확인.

## 성과 수집
각 게시물: 게시 ID, KST 시각, 유형, 첫 문장 유형, 글자 수, 이미지 여부, 조회/좋아요/댓글/재게시/공유/저장/프로필 방문/신규 팔로워/사이트 유입. 제공 불가 항목은 0이 아닌 `미확인`.
24h/72h/7d 누적 스냅샷 저장; 동일 게시물의 동일 시점 중복 수집 방지.
조회수 중앙값, 좋아요율/댓글률/공유율/저장률, 팔로워 전환율, 홈페이지 유입 비교. 분모 0/미확인 시 계산 금지. 사이트 유입은 추적 근거가 있을 때만 귀속.
초기 14일 기존 시간·게시량·교대 유지, 첫 문장과 본문만 비교. 표본 수와 주제·시간·이미지 교란요인 명시. 조회수만으로 승패 결정 금지.

## 검증 및 완료 게이트
- 실행기 실제 파일과 현재 예약/원장/이미지 교대 마지막 상태 조회
- 변경 전 성과 기준선 보존
- 샘플 3건 검수
- 코드 연동 및 테스트, 실제 배포 버전 기록
- 신규 정규 예약 2회 연속 실제 게시 ID 확인
- 24h/72h/7d 지표, 14일 비교 보고
- 설정 변경 / 코드 반영 / 배포 / 실제 게시 성공을 각각 별도 상태로 보고

**이 문서만 병합해도 게시기 동작은 바뀌지 않는다. 실제 게시기 연결과 정규 예약 검증이 완료되기 전에는 적용 완료를 선언하지 않는다.**
