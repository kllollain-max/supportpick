## 공개 버전 불일치

실패 실행 41921889569의 수집·후보 승격·로컬 검증·Pages 배포는 성공했고 2026-11-05 07:13:46 KST `public_generation_mismatch`로 실패했다. 기대 세대는 gov24-41921889569-1, 코드 SHA는 1d835c70be865938c90e4c6a278dfbbd8f058669였다. 당시 검사에서 실제 관측 세대·응답 헤더를 기록하지 않아 캐시와 배포 반영 지연, 다른 배포의 혼재 중 어느 것이 원인이었는지 사후 확정할 수 없다. 이후 배포 41930788660은 해당 자료 세대를 복원해 전수 검사 11,058개 통과했다.

기존 latest artifact 선택·immutable snapshot 해시·stale-head·배포 concurrency 보호는 유지한다. 공개 반영 단계만 최대 3회/5초 간격으로 기다린다. 기대 SHA·세대·fingerprint·전체 파일 해시 목록이 모두 일치해야 다음 검사로 진행한다. 검증 대상 값을 원격 값으로 바꾸지 않는다. data·현재 세대 shard 전체의 해시/세대/ID 집합을 대조하고 검사 종료 시 manifest가 바뀌지 않았는지 확인한다. 실패 시 기대/실제 관측을 report에 보존한다. ## R2

두 기존 설정 명명법을 지원하되 같은 값의 별칭만 허용한다. Secret 값은 출력하지 않는다. 업로드는 If-None-Match 조건으로 기존 객체를 덮어쓰지 않는다. 전체 다운로드 해시와 파일별 해시·크기, 상태/건수·코드 SHA를 검사하고 별도 임시 환경에서 재빌드·페이지 검증한다. 재빌드가 성공한 뒤에만 immutable 검증 영수증을 작성한다. 최신 정상본은 영수증의 수집 완료 시각으로 결정하므로 늦은 구세대 실행이 최신 표시를 덮어쓰지 못한다. 자동 삭제·공개 버킷·개인 브라우저 기록 백업은 추가하지 않는다.

기존 운영에서 정상 수집 후 업로드 및 매회 격리 복원 재빌드를 준비하며, 백업 실패 때문에 이미 검증된 수집·사이트 배포를 버리지 않고 회차 끝에 별도 실패로 보고한다. 신규 보관분의 GitHub 아티팩트 유지기간은 90일로 제안한다. 이미 생성된 아티팩트의 만료 시각은 변경하지 않는다. R2 실제 결과는 검증 실행의 별도 보고서에서 확인해야 하며 코드 구현만으로 완료가 아니다.
