## 변경된 동작

첫 화면은 30건을 먼저 표시하고 해시가 포함된 불변 catalog에서 같은 세대의 전체 데이터를 읽는다. 전체 조회 실패나 버전 불일치 시 일부 목록임을 알리고 재시도를 제공한다. 원래 data.json/data.js와 상세 API, 개인 기록 키와 형식은 보존한다.

지역·분야·대상·지원방식에 공식 API의 연령·가구 분류와 기간 상태를 추가했다. 미표기 자료 포함 여부를 선택할 수 있다. 필터는 수급 자격·현재 접수를 확정하지 않는다. 검색 텍스트·정렬 캐시와 입력 지연을 적용했다.

최대 3개 사업의 대상·지원내용·기간·방법·서류·조회일·출처를 비교한다. 보류 자료는 원문 확인으로 안내한다. 중복 수혜는 추정하지 않는다. 4편의 신청 준비 안내와 상세의 연령·가구 설명, 체크리스트를 추가했다.

명확한 단일 연도 생략 종료일만 해석한다. 연도 없는 기간, 복수 차수, 역전·잘못된 날짜를 임의로 보완하지 않는다. 원본은 바꾸지 않는다.

전체 데이터 품질 보고서는 기간 불명확, 짧은 요약, 원본 표기 차이, 중복사업 검토 후보를 수집한다. 금액의 사실성·실제 접수·모든 외부 링크의 HTTP 유효성을 자동 검증한 것으로 표현하지 않는다.
