# 심사 직전 콘텐츠·개인정보 추가 확인

기준일: 2026-11-05 KST. 이번 단계는 읽기 전용 점검과 개인정보 문안 후보 준비다. Google 심사 요청·광고 활성화·계약 동의·원격 삭제를 실행하지 않았다. 이전 PR #24/#28은 이미 승인 병합·배포됐고 이번 문구는 별도 후보다.

## 확인된 실제 운영 사실

사용자는 커리어픽 문의 메일과 알림 구독정보의 삭제 요청을 본인이 직접 관리한다고 답했다. 문의 메일·내려받은 첨부자료는 ‘처리 후 필요 없으면 삭제’한다고 답했다. 이 답변을 사본 전체 파기·휴지통 비우기·Git 이력 삭제 완료, 고정 5/30/90일 보유 기준 채택 또는 외부 계약 체결로 확대하지 않는다. 실제 개인 메일·구독자·계약 원문을 읽거나 공개 저장소에 복사하지 않았다.

## AdSense 실제 계정 상태

공통 호스트 kllollain-max.github.io의 사이트 상세에 ‘검토 필요’, 사이트 소유권 확인 녹색 체크, 활성화된 ‘검토 요청’ 버튼을 확인했다. 실제 검토 요청은 누르지 않았다. 계정 목록의 ads.txt는 ‘찾을 수 없음’이며 마지막 표시는 11월 4일 17:21 KST다. 공개 루트 파일 정상 제공과 Google 계정의 갱신 상태를 구분한다. 다른 기존 사이트·계정·지급/광고 설정은 바꾸지 않았다.

## 콘텐츠 검토 범위

커리어픽 가이드 6편의 본문 전체와 지원금픽 해설 20개의 요약·체크·신청 순서·FAQ를 읽었다. 공식 사실과 자체 준비 방법, 가상 예시, 실제 접수·선정 판단을 구분하는 문장을 점검했다. 공개 버전 대조 26/26 통과. 커리어픽은 소스 HTML 바이트 해시, 지원금픽은 공개 HTML에 해설의 요약·체크·순서·FAQ 원문이 모두 포함되는지 대조했다. 사이트별 결과는 submission-evidence-20261105/published-content-match.json에 있다.

NCS 공정채용 FAQ/설명, 고용노동부 표준 근로계약 안내, 보건복지부 수급자 선정기준, 한국에너지공단의 에너지재단 사업 안내, LH 주거급여 안내를 추가 열람했다. 에너지 지원의 참고 페이지는 2025년 안내임을 확인했고 이전 년도 규모를 현재 금액으로 옮기지 않는 기존 설명을 유지했다. 주거급여 선정기준과 임차/자가별 신청 안내의 역할도 구분했다. 기존 출처를 잘못된 링크라고 추정하여 교체하지 않았다. 이번 확인을 20개 사업의 현재 접수·자격·금액 전수 재검증으로 표시하지 않는다. reviewedAt/validUntil·사람 검토 상태는 변경하지 않았다.

## 정책상 의무와 남은 확인

Google의 공식 정책은 광고 쿠키·제3자 데이터 이용·개인 맞춤 광고 선택권을 설명하고 관련 링크를 제공하도록 한다. 현재 광고를 요청하지 않는 상태와 도입 이후 안내를 구분한다. 소개·문의·사이트맵 및 원고 개수를 일률적인 승인 필수조건으로 취급하지 않는다.

문의 목적이 끝난 자료의 관리 사실 일부는 확인됐지만, OneSignal 구독정보와 비공개 발송 이력의 보유 상한·삭제 기한·원격 사본·Git 과거 이력·복원 방지 및 실제 적용 계약/국외 처리의 세부사항은 남아 있다. 개인정보처리방침에 ‘운영자 확인 중’이라고 적는 것만으로 이 문제가 해결됐다고 판단하지 않는다. 실제 운영 절차·근거가 확정되기 전 AdSense 신청 준비 완료를 선언하지 않는다. 기존 보유기간 계산기는 운영 삭제 기능이 아니다.

## 적용·검증·되돌리기

이번 공개 변경은 privacy.html뿐이다. 수집 원본·URL·개인 기록·웹푸시·Threads·블로그·백업 설정과 광고 코드에는 변경이 없다. 새로운 원고를 대량 생성하지 않았다. 로컬 재빌드/정적 검사와 새 PR CI를 검증한다. 승인된 범위를 넘는 새 문안의 병합·공개 배포는 아직 수행하지 않았다. 되돌리기는 이 문안만 역커밋하며 정상 수집 자료·원장·개인 기록을 초기화하지 않는다.

## 이 저장소의 문구 변경

기존 광고 도입 조건 설명 아래 Google의 파트너 사이트 데이터 이용과 광고 선택·거부 설정 링크를 추가했다. GitHub 호스팅의 공식 개인정보 안내도 연결했다. 현재 광고가 활성화됐다고 표시하거나 제공자 로그를 운영자가 완전 삭제할 수 있다고 약속하지 않는다.
