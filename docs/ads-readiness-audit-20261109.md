# 광고 수익화 준비 점검 (2026-11-09)

> 문서 전용 Draft PR. 배포 파일, 예약 작업, 수집기, 게시기는 수정하지 않음. AdSense 승인을 주장하지 않음.

## 확인된 사실
- 저장소 기본 브랜치의 index.html을 확인함.
- 루트 ads.txt는 발견되지 않음. 승인 전에는 발행자 ID를 추정하거나 파일을 생성하지 않음.
- index.html에 \`<meta name="robots" content="noindex,nofollow">\`가 존재함. 검색 색인 차단 원인을 확인하고 운영자 승인 후 별도 변경 PR 필요.
- 루트 robots.txt를 찾지 못함. GitHub Pages 프로젝트 경로와 사이트맵 위치 확인 필요.

## 계정 소유자가 확인할 사항
1. AdSense > 사이트에서 정확한 URL과 상태(준비됨/검토 중/주의 필요/미등록) 확인. 계정 화면 없이는 승인 여부 단정 불가.
2. Search Console에서 사이트 소유권, 색인, 사이트맵, 검색 노출 확인.
3. 개인정보처리방침, 운영자 연락처, 독자에게 유용한 고유 콘텐츠, 모바일 UX 점검.
4. 광고 코드나 ads.txt는 실제 승인·발급된 게시자 ID와 플랫폼 요구사항 확인 후 별도 PR로 제안.
5. 외부 광고 스크립트, 사용자 추적 코드, noindex 수정은 별도 승인 전 금지.
