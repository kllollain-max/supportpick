# 학자금 차수 일정과 소상공인 자금 비교 보강

기준: 2026-11-17 KST. SupportPick 전용, PR71 병합 d970c9c7f19e65f9a8393815b92bf56fe153ab2d 이후 작업.

## 실제 발견과 수정

- 학자금대출 API의 날짜만으로는 11월 17일 18시 신청 종료를 반영하지 못했다. 한국장학재단 공식 일정으로 일반 신청과 실행, 전환대출을 구분했다.
- 국가장학금 3건은 API에 여러 신청 차수가 섞여 있다. 2026년 2학기 2차의 신청 종료와 서류·동의 종료를 별도 표기한다.
- 원본 해시가 일치하는 검토 안내에만 차수 일정을 연결한다. 검토 유효기간 최대30일, 이번7건은14일. 원문 변경·검토 만료·보류·잘못된 시간/출처이면 자동 적용하지 않는다.
- 공개 파생 목록의5건에만 `verifiedSchedule`을 추가한다. API 원본·이전 세대·상세 샤드·기존 공개 필드는 보존한다. 공개 data.json 자체는 의도적으로 변경된다.
- 목록·클라이언트 상세·정적 상세·마감 필터가 동일한 시각 기준을 사용한다. 후속 서류·대출 실행 마감을 새 신청의 연장으로 해석하지 않는다.
- 장학금·대출 비교1편, 직접·대리대출과 보증 비교1편을 작성하고7건과 왕복 연결한다. 취업 준비 원고나 다른 브랜드의 자료를 사용하지 않는다.
- 준비 안내20→27, 독자 해설17→19. 숫자는 AdSense 승인 기준이나 전체 저가치 문제 해소의 증거가 아니다.
